# ITI Ruby Course - Day 1 Task

This is my submission for **Day 1** of the ITI Ruby Course.

## 📚 Task Description

- Create an `Inventory` that holds many books.
- Each book has:
  - Title
  - Author
  - ISBN
- Store books in a file (using JSON).
- Basic features:
  - Add a book
  - Remove a book by ISBN
  - List all books

## ✨ Bonus Features

- If the book (by ISBN) already exists:
  - Increase its count
  - Update title/author if changed
- Search books by:
  - Title
  - Author
  - ISBN
- Sort books by ISBN
- Show messages if input is missing or incorrect

## 💾 File Storage

All books are saved in a file named `books.json`.

## 💡 How to Run

```bash
ruby inventory.rb
